# Weather Pet

A home-screen pet that blends in weather reporting. Live weather from Open-Meteo (no API key), Singapore as the default place, city search, hourly and 7-day forecasts, care meters, and a Moody personality by default.

Open the published GitHub Pages site — no build step needed. The four fluffy pet photos are embedded in `index.html` in this Pages version, so the single file works on its own.
